# Mon Pointage

Appli de pointage personnelle (arrivée, pause midi, retour, départ) avec temps restant sur le quota du jour et de la semaine.

Installable sur iPhone : ouvrir https://malmezat-gif.github.io/pointage/ dans Safari → Partager → « Sur l'écran d'accueil ».

Les données restent sur l'appareil (localStorage). Sources dans `src/` (`python3 src/build.py` reconstruit le site).
